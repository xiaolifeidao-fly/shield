案件列表接口
https://collection.cairin.id/xapi/v1/cases/list
POST

分页接口，带 cookie。系统设计上加一个开关，放到 shield_global_kv 里一个 kv 值，表示是否是第一次请求，初始为 false，本次任务结束后更新为 true。

false 时的请求参数，是全量数据。第一次请求同步全量数据
```json
{"action":3,"limit":100,"page":1,"searchKeyParam":{}}
```

true 时的请求参数，同步增量数据。
divisionTime 表示分配时间，默认是当天时间，开始及结束
```json
{"action":3,"limit":100,"page":1,"searchKeyParam":{},"divisionTimeStart":"2026-04-22 00:00:00","divisionTimeEnd":"2026-04-23 23:59:58"}
```


字段说明：
name：姓名
outSerialNo：合同编号
idCard：身份证号
mobile：手机号
userNo：案件的催收员
overdueDays：最长预期天数
bucket：账龄
gender：0 表示女

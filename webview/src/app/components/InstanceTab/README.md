# 业务分组功能说明

## 功能概述

新增了业务分组功能，支持在不同平台（抖音、快手、小红书）之间切换，每个分组都有独立的业务类型配置。

## 主要变更

### 1. 后端API接口

#### platform.config.api.ts
- 新增 `getBusinessGroups()` - 获取所有业务分组
- 新增 `getBusinessListByGroup(group: string)` - 根据分组获取业务列表

#### platform.api.impl.ts
- 实现了业务分组获取逻辑
- 支持DY、KS、XHS三个分组
- 每个分组返回对应的业务类型列表

### 2. 前端组件更新

#### BusinessTypeManager.tsx
- 新增业务分组选择器
- 支持在抖音、快手、小红书之间切换
- 切换分组时自动更新业务类型列表

#### useInstanceData.ts
- 新增 `businessGroups` 状态管理
- 新增 `currentGroup` 当前分组状态
- 新增 `switchBusinessGroup()` 分组切换方法
- 新增 `loadBusinessGroups()` 加载分组列表方法

#### InstanceTab.tsx
- 集成业务分组切换功能
- 当切换分组时，相关的休眠、业务类型、业务类型数量都会跟着变更
- 实例列表保持不变，只更新业务相关的数据

## 使用方法

1. **切换业务分组**：在业务类型管理区域，使用下拉选择器选择不同的平台分组
2. **配置业务类型**：选择分组后，可以配置该分组下的具体业务类型
3. **查看统计数据**：统计数据会根据当前选择的分组进行更新
4. **管理实例**：实例列表保持不变，但业务相关的操作会根据当前分组进行

## 技术特点

- **数据隔离**：不同分组的业务数据完全隔离
- **状态同步**：切换分组时自动同步相关数据
- **向后兼容**：保持原有功能不变，新增分组功能
- **实时更新**：统计数据实时根据当前分组更新

## 分组说明

- **DY（痘印）**：包含点赞、收藏、关注、CK播放、无CK播放等业务
- **KS（侩狩）**：包含点赞、收藏、关注等业务
- **XHS（小闳数）**：包含点赞、收藏、关注等业务

每个分组都有独立的业务类型配置和统计数据。
